# Quirks & Safety Notes:
# - Wi-Fi Ownership: Google TV's setup wizard (com.google.android.tungsten.setupwraith) owns the Wi-Fi
#   network created during initial TV onboarding. In Settings > Network & Internet, forget and re-join
#   the Wi-Fi before disabling setupwraith, or Android will drop the Wi-Fi profile and ADB connection.
# - Remote button remapping: Netflix and Prime Video buttons launch via HomeKeyService to SmartTube and Nuvio.
# - Live TV / HDMI: com.tcl.tv + com.tcl.tvinput; Input switcher: com.tcl.suspension.
# - DO NOT DISABLE: com.tcl.tv, com.tcl.tvinput, com.tcl.suspension, com.tcl.autopair,
#   com.tcl.systemui.plugin, com.tcl.systemserver, com.tcl.globalkeyoverlay,
#   com.realtek.android.tv.globalkeyoverlay, com.tpa.kb, com.tcl.factory.view, android core.
# - Private DNS: Configured to dns.adguard-dns.com for system-wide tracker/ad blocking.
